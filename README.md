## 💡 KMS Autoとは

**KMS Auto** は、お使いのコンピューター上で **Key Management Service (KMS)** をローカルにエミュレートする軽量なアクティベーションツールです。Microsoftは元々、大企業が1つの内部サーバーで数百台のデバイスをアクティベートできるようにKMSを設計しました。KMS Autoはその仕組みを個人のPC上で再現します — 外部サーバー不要、費用もかかりません。

### 主要コンポーネント

| コンポーネント | 機能 |
|---------------|------|
| 🖥️ **ローカルKMSホスト** | バックグラウンドでサービスとして動作 |
| 🔑 **GVLKキー** | 汎用ボリュームライセンスキー |
| ⏱️ **180日周期** | 各トークンは半年間有効 |
| 🔄 **更新タスク** | 毎日自動的にアクティベーションを延長 |

## 🔧 システム要件

```
✅ OS: Windows 10 または 11（全エディション）
✅ アーキテクチャ: x86（32ビット）または x64（64ビット）
✅ RAM: 最低 2GB（4GB 推奨）
✅ ディスク: 150MB の空き容量
✅ 権限: 管理者権限が必須
✅ .NET Framework: 4.0 以上
✅ Windows Defender: 一時的に無効化
✅ インターネット: 初回アクティベーション時に必要
✅ 復元ポイント: 強く推奨
```

> **⚠️ 重要なお知らせ:** システム変更の前に必ず復元ポイントを作成してください。**コントロールパネル → システム → システムの保護 → 作成** に進みます。

## 🪜 ステップバイステップ手順

### ステップ 1 — システムの準備

**Windows セキュリティ → ウイルスと脅威の防止 → 設定の管理 → リアルタイム保護 → オフ**。

除外フォルダを追加：

```
設定 → プライバシーとセキュリティ → Windows セキュリティ
→ ウイルスと脅威の防止 → 除外 → フォルダを追加
```

### ステップ 2 — アーカイブの解凍

ファイルを右クリック → **すべて展開…** → フォルダを選択。

### ステップ 3 — 管理者として実行

`KmsAuto.exe` を探す → 右クリック → **管理者として実行**。

> 💡 SmartScreen が表示されたら: **詳細情報 → 実行**。

</div>

### ステップ 4 — KMSサービスのインストール

メインウィンドウで **アクティベーション** をクリックし、**KMSサービスをインストール** を選択。コンポーネントは `C:\Windows\KMSAutoS` にインストールされます。

### ステップ 5 — Windowsのアクティベーション

**Windowsをアクティベート** をクリック。数秒後に緑色のチェックマークが表示されます。

### ステップ 6 — アクティベーション検証

**コマンドプロンプト** を管理者として開きます：

```bash
slmgr /xpr
```

成功すると **"永続的にアクティベートされました"** と表示されます。

詳細は：

```bash
slmgr /dlv
```

### ステップ 7 — 自動更新の確認

**タスクスケジューラ → タスクスケジューラライブラリ** を開き、KMSAuto タスクが有効であることを確認します。

### ステップ 8 — アンチウイルスの復元

リアルタイム保護を再度有効にし、KMSフォルダを除外リストに追加します。

### ステップ 9 — Officeのアクティベーション（任意）

**Office** タブに移動し、**Officeをアクティベート** をクリックします。

### ステップ 10 — 最終確認

**設定 → 更新とセキュリティ → ライセンス認証** で「Windowsはライセンス認証されています」を確認します。

## 🛠️ トラブルシューティング

| 問題 | 原因 | 解決策 |
|------|------|--------|
| ❌ アクティベーション失敗 | アンチウイルス | 無効化して再試行 |
| ❌ サービス起動失敗 | 権限不足 | 管理者として実行 |
| ❌ エラー 0xC004F074 | ネット接続なし | ネットワーク確認 |
| ❌ 再起動後ブラック画面 | サービスの競合 | セーフモード → 削除 |
| ❌ ライセンス早期失効 | タスク無効化 | KMSAuto タスク有効化 |
| ❌ Office未認証 | 間違ったタブ | Officeタブを使用 |
| ❌ Defenderがブロック | 誤検知 | 除外を追加 |
| ❌ エラー 0x803F7001 | ライセンスなし | GVLK再インストール |
| ❌ UACが出ない | 一般アカウント | 管理者でログイン |

## ❓ よくある質問

**KMS Autoは本当に無料ですか？**
はい — Microsoftが提供するKMSの仕組みを利用しています。

**アクティベーションはどのくらい持続しますか？**
180日間、毎日自動更新されるため、実質的に永続的です。

**Windows 10 22H2で動作しますか？**
はい、すべての最新ビルドでサポートされています。

**システムに害はありませんか？**
いいえ、重要なシステムファイルは変更されません。

**後でアンインストールできますか？**
はい — アンインストーラーまたはクリーンアップコマンドで可能です。

**Officeもアクティベートしますか？**
はい、Office 2013〜2021 および 365 ボリューム版。

**なぜアンチウイルスが反応するのですか？**
PUPとして分類されるため — 通常は誤検知です。

**毎日インターネットが必要ですか？**
いいえ、初回セットアップ時のみです。

**PCが遅くなりますか？**
いいえ、リソース消費は最小限です。

**更新後に再実行が必要ですか？**
通常は不要ですが、大規模更新後は必要になる場合があります。
